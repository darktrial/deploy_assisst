GT One-Click Dispatch

Select an available resource point → press F8 or click the toolbar icon → army preset slot 1 → dispatch → speed up until remaining time is ≤ 1 second (no fixed item limit).

Blue …: running / green ✓: arrived and gathering / orange !: check the log. Stop shortcut: Alt+Shift+X.
