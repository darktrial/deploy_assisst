# 異常與降級

| 狀況 | 當前流程／維護動作 | 重試上限 |
| --- | --- | --- |
| 版本／class／method 不符 | 停止原生流程，分析匹配 build，保留舊 profile 證據 | 遊戲動作 0 次自動重送 |
| 目標改變、占用、額外視窗、兵力零 | 停止並顯示原因，使用者先處理遊戲狀態 | 0 |
| 出征回應逾時／多新 queue | 不猜隊伍，不加速未知 queue | 0 |
| 加速回應逾時 | 不發下一個，不重發已送指令 | 0 |
| 抵達超過兩分鐘／queue 消失 | 明確未確認抵達；軍隊可能繼續行軍 | 不追加道具 |
| 主版 documentId 消失、導航或 scripting 權限不足 | 停止後續操作並顯示錯誤；重新選目標後再啟動 | 不沿用新 document，不重送 |
| 舊版 debugger 被占用、detach、導航 | 顯示失敗或取消，finally 清理可用連線 | 不自動換頁或換帳號 |
| F8 更新後無效 | 新路徑載入 extension，刷新遊戲再測焦點；檢查 trusted/repeat/輸入區 | 不用合成事件繞過 isTrusted |
| Python 依賴找不到 | 核對 GT_RESEARCH_DEPS 與搬移後 parents 路徑；先跑標準庫驗證 | 同一無改變命令不重複 |
| Graphify 找不到 | 核對 GRAPHIFY_PYTHON、來源雙層資料夾與安裝版本；用原碼完成局部研究 | 診斷後最多 3 次 |
| Graph query ambiguous／no match | 指定 node ID；匿名處理器改查實碼，保留 gap | 不把無結果視為無依賴 |
| Node／ZIP／索引驗證失敗 | 定位實際輸出，修正相對路徑或白名單；不刪掉測試掩蓋錯誤 | 3 次失敗後改最小重現 |
| storage 配額或 service worker 結束 | 檢查 session 紀錄是否仍存在；不僅憑舊 running 狀態推斷在執行 | 不自動恢復出征 |
| Coverity／實機環境缺失 | 記 Not Run、缺少項與影響，完成其他獨立驗證 | 不捏造通過結果 |

模板預設的工具呼叫重試不適用遊戲出征／道具副作用。只有純讀取或離線可重建操作才考慮重試。超出原授權／缺少必要決策時才提問；工具失敗本身不構成再次索取已授權權限的理由。
