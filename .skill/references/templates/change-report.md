# 變更紀錄填寫格式

填寫實際內容，不保留空的佔位欄位或把 Not Run 改寫成成功。文件型模板不含可執行示範程式。

1. **目的與範圍**：主版／舊版／研究工具，使用者預期行為。
2. **實作與影響**：主要檔案、caller/consumer、保留或變更的資料契約。
3. **來源證據**：revision（沒有提交就明確寫無）、可取得檔案／artifact、必要 SHA-256。
4. **驗證**：命令、exit code、Node/Python/Chrome 環境、oracle、mock 限制；Not Run 附原因。
5. **Graphify**：是否觸發更新、query/path/explain、實碼核對、cache 清理結果、knowledge gaps。
6. **發佈與復原**：ZIP 白名單、版本、Chrome 載入路徑、資料保存影響。
7. **剩餘事項**：區分已完成、待驗證、需使用者決策；實機道具實際消耗只按證據填寫。
